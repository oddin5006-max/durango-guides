공룡 도감

나무위키 「야생의 땅: 듀랑고/동물」 페이지를 기반으로 정리했습니다. 같은 동물이 여러 기후에 다른 모습으로 등장할 수 있습니다.

초반 / 초원·열대

콤프소그나투스

소형
가죽: 가벼움 경향 → 회피↑
뼈: 날카로운 단면 경향

유저가 가장 먼저 만나는 공룡. 무리로 다니며 초반 사냥 대상.

랩터

공격적
가죽: 가벼움 → 회피↑
뼈: 날카로운 단면 → 부위파괴↑

여러 지역에 등장. 무리 행동, 점프 공격. 깃털 드랍.

갈리미무스

중형
가죽: 가벼움 → 회피↑
뼈: 가벼움 → 정확도↑

빠른 이동. 무리로 다니며 인식 범위가 넓음.

뼈: 단단함 / 골판 → 공격력↑

트리케라톱스 계열

뼈: 단단함 → 공격력↑

뼈: 단단함 / 치밀한 구조 → 공격력·치명도↑

최상위 포식자. 최고급 재료 수급.

가공 레시피

참고: 꽃피다 블로그, 네이버 공략글, 나무위키. 가공 횟수가 남아 있는 재료에만 적용 가능하며, 주재료의 속성이 계승됩니다. 옵션 레벨은 (옵션 총합 / 투입 개수)에서 소수점 버림으로 계산됩니다.

일반 재료 가공 (돌 · 나무 · 뼈)

압착(압축) 가공

다듬은 재료 + 물 2개
효과: 높은 밀도 +3 → 내구도 상승

표면 가공

다듬은 재료 + 진액 1개
효과: 가벼움 +3 → 정확도 상승

정밀 가공

다듬은 재료 + 소금 2개
효과: 치밀한 구조 +3 → 치명도 상승

파편 가공

다듬은 재료 + 유리 파편 2개
효과: 단단함 +3 → 공격력 상승 + 낮은 밀도1 (내구도 감소)

금속 재료 가공 (정련)

금속 탄소 처리

진흙 3개 + 숯 2개
효과: 단단함 (공격력 증가) + 낮은 밀도 (내구도 감소)

금속 열 처리

기름 1개 + 숯 3개
효과: 가벼움 (정확도 증가) + 치밀한 구조 (치명도 증가)

금속 탈황 처리

조개껍질 2개 + 숯 2개
효과: 높은 밀도 (내구도 증가)

가죽 무두질

섬유질 무두질

껍질 1 + 잎 2 (또는 섬유)
효과: 높은 밀도 → 내구도 증가

명반 무두질

명반 2개
효과: 가벼움 → 회피 증가

기름 무두질

기름 1개
효과: 질긴 섬유 → 방어력 증가 + 낮은 밀도(내구도 감소)

기타 참고

건조

생재료 → 건조된 재료
효과: 보존 기간 증가, 이후 고급 가공 가능

천 제작

질긴 천: 질긴 섬유 (방어↑)
두꺼운 천: 높은 밀도 (내구↑)
부드러운 천: 고급스러움 (매력↑)

무기 장식

돌 장식: 맷집 (최대 건강·에너지↑)
뼈 장식: 솜씨 (치명↑) + 의지
이빨 장식: 민첩 (정확·회피↑) + 의지
상아 장식: 힘 (공격·방어관통↑) + 맷집

의상 개조

옷감 덜기: 더위 저항
솜 덧대기: 추위 저항
볕가리개: 땡볕 저항
통기성 개조: 습기 저항
바람막이: 강풍 저항
주머니 달기: 소지량 증가

음식 가공

음식 가공은 무기 가공보다 방대하며, 핵심은 가공 횟수 초기화와 버프 누적을 이용한 다단계 조리입니다. 응용 요리(빵, 완자, 떡 등)로 제작 시 가공 횟수가 초기화되는 특권이 있습니다.

건강 회복 관련

말린 약초 (가성비 최고)

건조대에서 라벤더·보라튤립 등 약초를 말리기 가공.
대량 생산 쉽고 평소 필드 활동에 가장 많이 사용되던 국민 아이템.

환약 (극한 회복량)

약 제조대 + 절구 + 건조 사용.
건강 회복 속성이 붙은 고레벨 약재를 주재료로 사용.
가공 횟수를 끝까지 반복하면 단 한 알로 대량 건강 회복 가능. 고난도 레이드용 비상약.

환약 + 날약초 콤보

먼저 환약으로 건강 보충 후 지혈제·날약초를 사용하면 회복 효과 상승.

고레벨 추천 음식 레시피

양념치킨 (Lv.60)

사냥·도축용 요리. 60레벨 기준 힘168, 눈치112
힘: 공격력·방어관통 / 눈치: 도축능력 상승 → 잠재옵션 획득 용이
제작: 오일소스 제작(기름+소금) → 곡물 빻기 → 고기+곡물가루+기름+오일소스+우유 → 양념치킨 소금 돌판구이 → 찌기

크림케이크 (Lv.57)

채집용 요리. 57레벨 기준 솜씨140, 눈치138
솜씨: 채집능력·채광능력 / 눈치: 은신능력 상승 → 전투 횟수 감소
제작: 크림제작(우유+설탕) → 버터제작(우유+소금) → 곡물가루 빵기x2 → 곡물가루 단짠굽기1 → 케이크 반죽(곡물가루 돌판구이+버터+설탕) → 크림케이크 제작(케이크 반죽+크림+과일) → 크림케이크 찌기

고기빵 (Lv.60)

사냥·채집·공용·전쟁용·무기제작. 60레벨 기준 힘161, 솜씨126
힘: 공격력·방어관통·무기제작능력 / 솜씨: 치명타·무기제작능력
제작: 곡물가루 빵기 → 효모제작(과일3) → 곡물가루 단짠굽기1 → 반죽(곡물가루 돌판구이+효모) → 고기빵제작(반죽+고기) → 고기빵 찌기

과일피자(조각) (Lv.59)

방어구 제작·재봉·요리. 59레벨 기준 솜씨144, 매력77
솜씨: 옷 제작능력 / 매력: 재봉능력·요리능력
제작: 치즈제작(우유3+소금1) → 곡물가루 빵기x2 → 효모제작x2(과일3) → 곡물가루 단짠굽기x2 → 빵 반죽x2(곡물가루 돌판구이+효모) → 피자제작(빵반죽2+치즈+포도or무화과) → 피자 찌기

애벌레 (Lv.60)

공예·금속가공·농사. 60레벨 기준 의지140
의지: 공예능력·금속가공능력·농사능력
제작: 애벌레 약초구이 → 찌기

보충 설명

1. 단짠굽기는 설탕구이+소금구이를 줄인겁니다.
2. 무기제작 능력 붙은 류의 요리보다 고기빵이 더 좋아요.
3. 크림케이크는 떡볶이로 대체됩니다.
4. 햄버거가 고기빵보다 좋지만 큰 차이는 안나고 찔 수가 없습니다.
5. 고기피자 / 과일빵은 재료만 바뀌서 쓰시면 됩니다.
6. 과일쥬는 60기준 의지120이 안됩니다. 별레 구워드세요.
7. 왜 자꾸 찌나요? → 버프 시간이 증가되고, 다른 재료를 요구하지 않고, 외형이 고정되어 창고에서 찾기 좋습니다.
8. 곡물단계에서 가공은 왜 안하나요? → 귀찮아요.

PvP(무법섬) 및 고레벨 사냥 기준. 클릭해서 해당 내용을 확인하세요.

석궁 (두머리뼈석궁대 등)

후반부·레이드(티라노 등)에서 자주 쓰인 고성능 원거리 무기.
공격 속도가 활보다 빠르고, 경직·기절·넉백 효과가 있음.

핵심 재료: 가공된 갈비뼈 (주재료). 금속은 부재료.
주재료 뼈의 옵션이 그대로 계승됨.

추천 옵션: 방어 관통(뾰족함), 정확도, 공격력.
알로사우루스·티라노 뼈: 뾰족함 Lv4 기본 부여 (무거움 패널티 있음 → 표면 가공으로 보완).

무기 옵션 수치 (참고):
단단함: 공격력 +약 3.25 / 레벨 (최대 Lv21)
치밀한 구조: 치명타 +약 0.67 / 레벨 (최대 Lv18)
가벼움: 명중률 +약 4 / 레벨 (최대 Lv18)
높은 밀도: 내구도 +약 10 / 레벨

한손검

근접전의 제왕. 공격 속도가 가장 빠르고 선후딜이 짧아 기동성이 뛰어남.
구르기로 원거리 공격을 파훼하기 쉬움.

1:1 대인전에서 석궁을 상성상 이김 (구르기 진입 + 빠른 공속).
다대다에서는 앞라인 탱커/브루저 역할이 중요.

창 (장창)

1:1 대인전과 부족전(공성전) 양쪽에서 변수를 만드는 근접 무기의 재발견 아이템이자 조커 픽.

장점
• 압도적인 근접 사거리 (450) — 상대는 못 때리는데 나는 찌를 수 있는 거리 유지 가능
• 순간 폭딜 원탑 '장창 돌격' — 구르기 뺀 타이밍에 꽂으면 판금·화산갑도 한 방에 실사 가능
• 부족전(거점 공성전)의 황제 — 방어탑·담장에 가장 강력한 대미지. 방검 유저가 어그로 끄는 동안 돌격으로 거점 파괴

한계점
• 낮은 정확도·치명도 패널티 — 회피율 높은 민첩/가죽 세팅에게 빗나갈 확률 높음
• 수비태세/방패 유저에게 무력 — 돌격 대미지가 막히고 내구도만 깎임. 피하는 것이 좋음

추천 세팅
1. 원재료: 깡딜 → 타르보사우루스·고레벨 스밀로돈 뼈(단단함) / 떡장갑 찢기 → 알로사우루스 뼈(뾰족함)
2. 2차 가공: 반드시 표면 가공(진액) → 가벼움(정확도↑)으로 낮은 명중 보완
3. 실전: 먼저 돌격 박지 말 것. 평타 찌르기로 간 보다가 적이 구르기 쓰는 순간 후딜에 장창 돌격 꽂기

활

다인전에서 프리딜이 나오면 딜량이 압도적으로 높음.

그러나 1:1에서는 취약
• 한손검이 구르기 쓰면서 붙으면 끔살
• 석궁보다 공속이 느리고 석궁처럼 스턴을 못 넣어서 끔살
• 창 돌진으로 붙으면 끔살

1:1 대인전

한손검 > 석궁 (평균 승률)
한손검: 구르기로 진입 + 빠른 공속으로 카이팅을 막음.
석궁: 선제 스턴·넉백 성공 시 역전 가능.

활이 석궁보다 대인전 딜량에서 약간 더 높게 평가됨 (패시브 명중·방어무시).

3:3 / 5:5 팀전

3:3 — 석궁(원거리) 조합이 유리.
일점사 + 메즈 연계로 진입 전에 녹임.

5:5 — 2한손검 + 3석궁 (밸런스) > 5석궁.
한손검이 앞을 막아주는 동안 석궁이 프리딜. 올원거리는 물리면 쉽게 붕괴.

가공 & 옵션 (PvP 기준)

PvP에서는 방관(뾰족함) 올인 추천.
상대 방어력이 높으면 공격력이 높아도 딜이 안 들어감. 방관이 있어야 죽창 딜이 나옴.

가공 우선순위 (뼈):
1. 파편 가공 (유리 2) → 단단함 (공격력↑) / 내구↓ — 깡딜 보완에 최고
2. 표면 가공 (진액 1) → 가벼움 (정확도↑) — 무거움 패널티 보완
정밀·압축 가공은 전투 효율 낮음.

뾰족함 높은 뼈: 알로사우루스 (Lv4 고정), 티라노, 켄트로·안킬로 등 가시/뿔 공룡.

기본 원칙

무기와 옷의 옵션은 첫 번째 재료(주재료)의 속성을 계승합니다.
칼 → 칼날, 활 → 활대, 가죽옷 → 가죽, 천옷 → 천
가급적 뼈와 나무는 전부 다듬어 두는 것이 좋습니다. 가공 횟수 0이어도 제작 가능.

섬 · 기후

각 기후별로 필요한 주요 저항입니다. 저항이 부족하면 피로도가 빠르게 증가합니다. (나무위키 및 공략글 기반)

열대

필요 저항: 더위 저항
고온으로 인해 피로도가 빠르게 쌓임. 얇음·통기성 좋은 의상이 유리.

온대 / 초원

필요 저항: 특별히 없음 (초보자 추천)
가장 안정적인 기후. 기본 장비로도 활동 가능.

툰드라

필요 저항: 추위 저항
낮은 기온으로 피로도 증가. 푹신함 속성이 유용.

설원

필요 저항: 강풍 저항
강한 바람으로 인한 피로도 증가. 매머드 가죽의 기름진(강풍 저항)이 대표적.

늪지

필요 저항: 습기 저항
높은 습기로 피로도 증가. 좋은 통기성 속성이 유리.

사막

필요 저항: 더위 저항 + 땡볕 저항
고온과 직사광선. 흑요석 등 특수 자원 존재.

화산

필요 저항: 더위 저항 (최고 레벨 지역)
극한 고온. 고레벨 장비와 저항이 필수.
